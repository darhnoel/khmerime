មកដល់ឆាប់ៗ។ ពេលនេះ សូមសាកល្បងតាម Web។

  1. ទាញយក ហើយបើកឯកសារ .msi ដើម្បីដំឡើង។
  2. បើក Settings → Time & language → Language & region។ បើមិនទាន់មានភាសាខ្មែរ ចុច Add a language ហើយបន្ថែម Khmer។
  3. ចុច Win + Space ហើយជ្រើស KhmerIME។ បើមិនឃើញ៖ Khmer → ⋯ → Language options → Add a keyboard → KhmerIME។
